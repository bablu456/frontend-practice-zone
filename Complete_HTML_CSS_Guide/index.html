Text Formatting Tags

Basic Text Tags

Strong tag: This text is wrapped in strong tag, which makes it bold and tells search engines it's important.

Emphasis tag: This text is in em tag, which makes it italic and emphasizes meaning.

Underline: This text uses u tag which underlines text (use sparingly as it can confuse with links).

Highlighted text: The mark tag highlights text with yellow background, like a marker pen.

Small text: The small tag makes text smaller - useful for fine print.

Deleted text: The del tag shows strikethrough - useful to show removed content.

Inserted text: The ins tag shows underline - useful to show added content.

Code tag: The code tag displays text in monospace font, used for computer code.

Formula: H2O uses sub tag for subscript (text below the line).

E=mc2 uses sup tag for superscript (text above the line).

Semantic HTML Tags

Article Title: Understanding Semantic HTML

Published on January 15, 2024

Semantic HTML means using tags that clearly describe their content. This helps search engines, screen readers, and other developers understand your code better.

Written by John Developer

Did You Know?

Using semantic HTML improves:

  • Search engine rankings (SEO)
  • Accessibility for users with screen readers
  • Code readability for other developers
